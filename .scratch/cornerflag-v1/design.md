# CornerFlag v1 — 디자인

[spec.md](spec.md)에서 정한 내용 중 "어떤 화면과 버튼이 있고, 무엇을 표시하는지"만 모은 문서다. 레이아웃, 크기, 글꼴, 색 수치 같은 세부 디자인은 아직 정하지 않았다.

- 근거가 된 질문과 답: [qa.md](qa.md) (본문의 `Q#`는 그 문서의 질문 번호)
- 동작 규칙(어떤 경기를 보여줄지, 갱신, 오류 처리): [spec.md](spec.md)

## 1. 화면 목록

| 화면 | 언제 |
|---|---|
| 위젯 카드 | 항상. 바탕화면에 고정 |
| 첫 실행 화면 | 처음 실행할 때 |
| 설정 화면 | 메뉴의 Settings |
| 메뉴 | 트레이 아이콘 클릭, 위젯 우클릭 |

UI 문구는 모두 영어다 (Q16).

## 2. 위젯 카드

한 번에 경기 하나만 표시한다 (Q22). 어떤 경기를 고를지는 [spec.md](spec.md) 5.1절을 따른다.

### 2.1 공통 요소

- 홈팀이 왼쪽, 원정팀이 오른쪽. 별도의 홈/원정 배지는 없다 (Q13).
- 팀 로고 (Q13)
- 팀명: ESPN `displayName`, 길면 말줄임 (Q15)
- 대회명: ESPN `league.abbreviation` (예: `Premier League`, `UEFA Champions League`) (Q13)

### 2.2 상태별 표시 내용

| 상태 | 표시 내용 |
|---|---|
| 다음 경기 | 공통 요소 + 킥오프 날짜·시각. 절대 표기, 로컬 타임존 기준 (예: `Oct 24 (Sat) 20:00`). 12·24시간제는 설정을 따른다 (Q21) |
| 다음 경기 (연기됨) | 위 내용 + `Postponed` 배지. 원래 킥오프 시각까지만 표시 (Q20) |
| 실시간 | 공통 요소 + 스코어 + 경기 상태(ESPN `status.type.shortDetail`, 예: `67'`, `HT`) + 가장 최근 득점 한 줄 (Q14) |
| 직전 결과 | 공통 요소 + 최종 스코어. 승부차기는 `1–1 (4–3 PEN)` |
| 경기 없음 | `No upcoming matches` (Q30) |

득점 줄:
- 형식은 `Goal! 67' Haaland`이고, 가장 최근 득점 한 건만 보여준다.
- ESPN이 정보를 주면 PK는 `(P)`, 자책골은 `(OG)`를 붙인다.
- 경기가 끝나면 없앤다 (Q18).

### 2.3 색

- 배경: 반투명 아크릴릭. 투명도는 설정에서 조절한다 (Q26, Q27).
- 직전 결과: 이긴 팀의 색으로 위젯을 은은하게 칠한다. 무승부는 중립색 (Q13).
- 실시간: 리드하는 팀의 색으로 칠한다. 동점이면 중립색 (Q17).
- 팀 색은 ESPN 팀 `color` 값을 그대로 쓴다. 흰색·검정 팀도 예외 없이 그 색이다. 값이 없으면 중립색 (Q36).
- 다음 경기, 경기 없음: 중립색.

## 3. 버튼과 조작

| 대상 | 조작 | 결과 |
|---|---|---|
| 카드 아무 곳 | 클릭 | 기본 브라우저로 구글 검색 (검색어 형식은 [spec.md](spec.md) 5.2절) (Q23) |
| 카드 아무 곳 | 드래그 | 위젯 이동. 위치 잠금이 켜져 있으면 움직이지 않음 (Q6, Q27) |
| 새로고침 버튼 ↻ | 클릭 | 즉시 갱신. 마우스를 카드 위에 올릴 때만 보임. 5초 쿨다운 (Q24) |
| 카드 | 우클릭 | 메뉴 열기 (Q7) |
| 트레이 아이콘 | 클릭 | 메뉴 열기 (Q7) |
| 업데이트 표시 | 클릭 | 설치본은 업데이트 설치 후 재시작, zip은 Releases 페이지 열기 (Q4) |

클릭과 드래그는 누른 뒤 움직인 거리로 구분한다.

메뉴 항목 (트레이와 우클릭 공통):
- `Settings`
- `Refresh`
- `Quit`

## 4. 상태 표시

| 표시 | 언제 | 내용 |
|---|---|---|
| ⚠ 아이콘 | 갱신이 연속 2회 실패 (Q31) | 마우스를 올리면 마지막 갱신 시각 |
| ⚠ 툴팁 (요청 제한) | `429`·`403`으로 대기 중 | 다음 시도 시각. 이 동안 ↻ 비활성 |
| ⚠ 툴팁 (영구 오류) | 요청 자체가 잘못됨 | `Data unavailable — update may be required` |
| 업데이트 표시 | 새 버전이 있음 (Q4) | 작은 표시. 클릭 동작은 3절 |

오류 분류와 재시도 규칙은 [spec.md](spec.md) 8절에 있다.

## 5. 첫 실행 화면

순서대로 진행한다 (Q8, Q12).

1. 리그 선택: EPL, LALIGA, Bundesliga, Serie A, Ligue 1 (Q9)
2. 팀 선택: 고른 리그의 팀 목록 (로고 + 팀명)
3. `Start with Windows` 체크박스
4. 완료 → 위젯 표시

## 6. 설정 화면

| 항목 | 형태 |
|---|---|
| 응원 팀 | 첫 실행과 같은 리그 → 팀 선택 |
| Windows 시작 시 실행 | 켜기/끄기 |
| 투명도 | 조절 |
| 위치 잠금 | 켜기/끄기 |
| 12·24시간제 | 선택 |

## 7. 정해야 할 것

- 카드 레이아웃과 크기
- 글꼴, 글자 크기
- 아크릴릭 바탕 톤(다크·라이트)과 중립색
- 팀 색 틴트의 방식과 강도
- 실시간 표시(LIVE 표시 방식 등), 아이콘 모양
- 첫 실행·설정 화면의 창 형태
