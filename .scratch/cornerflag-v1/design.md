# CornerFlag v1 — 디자인

[spec.md](spec.md)에서 정한 내용 중 화면, 버튼, 표시 내용과 시각 디자인(레이아웃, 색, 글꼴, 크기)을 모은 문서다.

- 근거가 된 질문과 답: [qa.md](qa.md) (본문의 `Q#`는 그 문서의 질문 번호)
- 동작 규칙(어떤 경기를 보여줄지, 갱신, 오류 처리): [spec.md](spec.md)
- 목업: [mockup.html](mockup.html). 브라우저로 열면 상태별 카드를 보고 글꼴·크기·틴트·불투명도를 바꿔 볼 수 있다. 수치가 다르면 이 문서를 따른다.

## 1. 화면 목록

| 화면 | 언제 |
|---|---|
| 위젯 카드 | 항상. 바탕화면에 고정 |
| 첫 실행 화면 | 처음 실행할 때 |
| 설정 화면 | 메뉴의 Settings |
| 메뉴 | 트레이 아이콘 클릭, 위젯 우클릭 |

UI 문구는 모두 영어다 (Q16).

## 2. 위젯 카드

한 번에 경기 하나만 표시한다 (Q22). 어떤 경기를 고를지는 [spec.md](spec.md) 5.1절을 따른다.

### 2.1 레이아웃

가로 대칭이다 (Q37). 홈팀이 왼쪽, 원정팀이 오른쪽이고 별도의 홈/원정 배지는 없다 (Q13).

```
┌──────────────────────────────────┐
│ Premier League                 ↻ │   머리 줄: 대회명, ↻(호버 시)
│   (MCI)       2 – 1      (ARS)   │   경기 줄: 홈 | 가운데 | 원정
│  Man City     ● 67'     Arsenal  │
│ ──────────────────────────────── │   구분선(실시간에만)
│ Goal! 67' Haaland  More details ↗│   바닥 줄: 득점 줄, More details(호버 시)
└──────────────────────────────────┘
```

- 카드는 세 줄로 나뉜다: 머리 줄, 경기 줄, 바닥 줄.
- 바닥 줄은 모든 상태에서 자리를 차지한다. 상태가 바뀌어도 경기 줄의 위치가 그대로 있게 하려는 것이다.
- 경기 줄의 가운데 칸은 폭 104px로 고정하고, 양쪽 팀 칸이 남은 폭을 나눈다.
- 팀 칸에는 로고(40px)를 위에, 팀명을 아래에 놓는다.
- 대회명과 로고 사이, 팀명과 구분선 사이는 각각 약 10px 띄운다 (Q54).
- 스코어는 홈 점수, `–`, 원정 점수의 세 칸으로 나눈다 (Q55).
  - 양쪽 칸의 폭이 같아서 `–`는 항상 카드 가로 중앙에 있다.
  - 홈 점수는 오른쪽 정렬, 원정 점수는 왼쪽 정렬이고, 둘 다 `–`에서 8px 떨어진다.
  - 점수가 두 자리가 되면 바깥쪽으로 늘어난다. 갱신할 때는 숫자만 바뀐다.
- 스코어 아래 줄은 `–`에 맞춰 가운데 정렬한다. 빨간 점과 경기 시간(`● 67'`)은 5px 간격의 한 묶음으로 정렬하고, 배지는 배지 전체를 정렬한다 (Q56).

### 2.2 공통 요소

- 팀 로고: ESPN 팀 `logos` 중 `rel`에 `dark`가 있는 것(어두운 배경용). 없으면 `default`를 쓴다 (예: Coventry City).
- 팀명: ESPN `shortDisplayName` (예: `Man City`, `Spurs`, `Nottm Forest`). 5대 리그에서 가장 긴 것이 13자(`Real Sociedad`)다. 넘치면 말줄임 (Q15, Q49).
- 대회명: ESPN `league.abbreviation` (예: `Premier League`, `UEFA Champions League`) (Q13)

### 2.3 상태별 표시 내용

| 상태 | 가운데 칸 | 바닥 줄 |
|---|---|---|
| 다음 경기 | 킥오프 날짜(위, 작게)와 시각(아래, 크게). 절대 표기, 로컬 타임존 기준 (예: `Oct 24 (Sat)` / `20:00`). 12·24시간제는 설정을 따른다 (Q21) | 비움 |
| 다음 경기 (연기됨) | 위 내용 + 빨간 `Postponed` 배지. 원래 킥오프 시각까지만 표시 (Q20, Q57) | 비움 |
| 실시간 | 스코어, 그 아래 깜빡이는 빨간 점 + 경기 상태(ESPN `status.type.shortDetail`, 예: `● 67'`, `● 90'+3'`). 하프타임(`HT`)은 점 없이 노란 `Half-Time` 배지 (Q14, Q41, Q53, Q57) | 구분선 + 가장 최근 득점 한 줄 (Q51) |
| 직전 결과 | 최종 스코어, 그 아래 이긴 팀 색의 `Full-Time` 배지. 연장으로 끝난 경기도 같다. 무승부는 중립 배지. 승부차기로 끝났으면 승부차기에서 이긴 팀 색의 `4–3 PEN` 배지 (Q52, Q57, Q58) | 비움 |
| 경기 없음 | 팀 칸 없이 카드 가운데에 `No upcoming matches` (Q30) | 없음 |

득점 줄:
- 형식은 `Goal! 67' Haaland`이고, 가장 최근 득점 한 건만 보여준다. 길면 말줄임.
- ESPN이 정보를 주면 PK는 `(P)`, 자책골은 `(OG)`를 붙인다.
- 경기가 끝나면 없앤다 (Q18).

깜빡이는 점은 2초 주기로 흐려졌다가 돌아온다. 애니메이션은 실시간 상태에서만 돈다.

### 2.4 색

- 톤: 다크 고정 (Q38). 아크릴릭 위에 `rgb(24 24 27)`을 덮고, 그 불투명도는 설정의 투명도 값을 따른다. 기본 70% (Q48).
- 글자: 기본은 흰색 95%. 보조 글자(대회명, 경기 상태, 날짜, 득점 줄, More details)는 흰색 62%.
- 테두리: 1px 흰색 9%. 모서리 반경 8px (Win11 창과 같음).
- 팀 색 틴트 (Q39, Q46, Q59):
  - 이기거나 리드하는 팀 쪽 가장자리(홈=왼쪽, 원정=오른쪽)에서 반대쪽 가장자리까지 선형 그라데이션으로 칠한다.
  - 시작 농도는 팀 색 40%, 반대쪽 끝은 0%. 결과 배지도 팀 색이라 틴트가 진하면 색이 겹쳐 보여서 낮췄다 (Q59).
  - 직전 결과는 이긴 팀 색으로 칠한다. 승부차기는 승부차기에서 이긴 팀이다 (Q13).
  - 실시간은 리드하는 팀 색으로 칠한다 (Q17).
  - 무승부, 실시간 동점, 다음 경기, 경기 없음은 틴트 없이 기본 바탕만 쓴다. 문서의 "중립색"은 이 상태를 말한다.
- 팀 색은 ESPN 팀 `color` 값을 그대로 쓴다. 흰색·검정 팀도 예외 없다. 값이 없으면 틴트 없음 (Q36). 다크 톤이라 검정 팀의 틴트는 거의 보이지 않는다.
- 실시간 점: `#ff3b30`
- 배지 (Q57): pill 모양, 글자 10.5px, 굵기 400. 기준색 하나로 글자와 바탕을 만든다.
  - 글자: 기준색 55% + 흰색 45%. 어두운 팀 색도 읽히게 하려는 것이다.
  - 바탕: 기준색 22%.
  - 기준색: `Half-Time`은 노랑 `#ffd60a`, `Postponed`는 빨강 `#ff3b30`, `Full-Time`과 `4–3 PEN`은 이긴 팀의 ESPN `color`.
  - 중립 배지(무승부 `Full-Time`): 글자는 보조 글자색, 바탕은 흰색 10%.

### 2.5 글꼴과 크기

- 글꼴: Outfit (Google Fonts, OFL, latin·latin-ext 포함). 오프라인에서도 보이도록 woff2 파일을 앱에 넣는다 (Q40, Q45).
- 기본 카드 크기: 320×146px (배율 100%, 100% DPI 기준). 가로세로 비율은 고정이고 설정에서 배율을 바꾼다 (Q47). 배율을 바꾸면 아래 수치가 모두 같은 비율로 커지거나 작아진다.

| 요소 | 크기 (배율 100%) | 굵기 |
|---|---|---|
| 스코어 | 30px | 700 |
| 다음 경기 시각 | 22.5px | 700 |
| 팀명 | 12.5px | 600 |
| 다음 경기 날짜 | 12px | 400 |
| 경기 상태, 득점 줄 | 11.5px | 400 |
| 대회명, More details | 11px | 500 |
| 카드 안쪽 여백 | 위 11px, 아래 12px, 좌우 14px | |
| 머리 줄 높이 / 아래 간격 | 16px / 5px | |
| 바닥 줄 높이 / 위 간격 | 23px(구분선 아래 6px 포함) / 5px | |
| 경기 줄 | 남는 높이 전부, 내용은 세로 가운데 | |

## 3. 버튼과 조작

| 대상 | 조작 | 결과 |
|---|---|---|
| 카드 아무 곳 | 클릭 | 기본 브라우저로 구글 검색 (검색어 형식은 [spec.md](spec.md) 5.2절) (Q23). 경기 없음 상태에서는 아무 일도 없음 |
| 카드 아무 곳 | 드래그 | 위젯 이동. 위치 잠금이 켜져 있으면 움직이지 않음 (Q6, Q27) |
| 카드 | 마우스 오버 | 오른쪽 위에 ↻, 오른쪽 아래에 `More details ↗` 표시 (Q24, Q50). 경기 없음 상태에서는 ↻만 |
| 새로고침 버튼 ↻ | 클릭 | 즉시 갱신. 5초 쿨다운 (Q24) |
| 카드 | 우클릭 | 메뉴 열기 (Q7) |
| 트레이 아이콘 | 클릭 | 메뉴 열기 (Q7) |
| 업데이트 표시 | 클릭 | 설치본은 업데이트 설치 후 재시작, zip은 Releases 페이지 열기 (Q4) |

- `More details ↗`는 별도 버튼이 아니다. "카드를 누르면 자세한 정보를 볼 수 있다"는 안내이고, 카드 어디를 눌러도 결과는 같다.
- 클릭과 드래그는 누른 뒤 움직인 거리로 구분한다.
- 아이콘(↻, ↗, ⚠)은 선 굵기 1.5px의 인라인 SVG다.

메뉴 항목 (트레이와 우클릭 공통):
- `Settings`
- `Refresh`
- `Quit`

## 4. 상태 표시

| 표시 | 언제 | 내용 |
|---|---|---|
| ⚠ 아이콘 | 갱신이 연속 2회 실패 (Q31) | 마우스를 올리면 마지막 갱신 시각 |
| ⚠ 툴팁 (요청 제한) | `429`·`403`으로 대기 중 | 다음 시도 시각. 이 동안 ↻ 비활성 |
| ⚠ 툴팁 (영구 오류) | 요청 자체가 잘못됨 | `Data unavailable — update may be required` |
| 업데이트 표시 | 새 버전이 있음 (Q4) | 작은 표시. 클릭 동작은 3절 |

오류 분류와 재시도 규칙은 [spec.md](spec.md) 8절에 있다.

## 5. 첫 실행 화면

한 화면에서 위에서 아래로 진행한다 (Q8, Q12, Q44).

```
┌ CornerFlag ───────────────────────── ✕ ┐
│ Pick your team                         │
│ [EPL] LALIGA Bundesliga Serie A Ligue 1│
│ (◉)  (◉)  (◉)  (◉)  (◉)                │
│  ...                                   │
│ ☐ Start with Windows                   │
│                              [ Start ] │
└────────────────────────────────────────┘
```

1. 리그 탭: EPL, LALIGA, Bundesliga, Serie A, Ligue 1 (Q9)
2. 팀 격자: 고른 리그의 팀을 로고 + `shortDisplayName`으로 5열 격자에 보여준다. 리그당 18~20팀이 스크롤 없이 들어간다 (Q43).
3. `Start with Windows` 체크박스
4. `Start` → 위젯 표시. 팀을 고르기 전에는 비활성.

### 5.1 창 형태

첫 실행 창과 설정 창은 위젯과 같은 프레임리스 다크 아크릴릭 창이다 (Q42).

- 제목 영역을 끌어서 옮긴다 (`data-tauri-drag-region`).
- 오른쪽 위 ✕로 닫는다. 첫 실행 창을 팀을 고르지 않고 닫으면 앱을 종료한다.
- 바탕화면에 고정하지 않는다. 일반 창처럼 다른 창 위에 뜬다.

## 6. 설정 화면

첫 실행 화면을 그대로 쓰고 아래 항목을 더한다 (Q44). 바꾼 값은 즉시 반영되므로 저장 버튼이 없다.

| 항목 | 형태 |
|---|---|
| 응원 팀 | 첫 실행과 같은 리그 탭 + 팀 격자 |
| Windows 시작 시 실행 | 켜기/끄기 |
| 크기 | 슬라이더. 비율 고정, 카드 너비 260–420px (배율 약 80–130%) (Q47) |
| 투명도 | 슬라이더. 기본 70% (Q48) |
| 위치 잠금 | 켜기/끄기 |
| 12·24시간제 | 선택 |

## 7. 정해야 할 것

- 트레이 아이콘과 앱 아이콘
- ⚠와 업데이트 표시의 모양
- 설정 화면 컨트롤(토글, 슬라이더)의 세부 모양
- 실제 SWCA 아크릴릭 위에서 틴트 40%와 불투명도 70% 재확인. 목업은 CSS `backdrop-filter`로 아크릴릭을 흉내 낸 것이라 실제 색감과 다를 수 있다.
