- 시각 디자인의 기준: Figma [CornerFlag — Widget Design](https://www.figma.com/design/yrP3oyV0Q8jD7d8fnP4nH3)
  - `Widget drafts` 페이지: 위젯 카드(`D CornerFlag (C + B)` 보드)와 `Motion` 섹션(Smart Animate 프로토타입)
  - `Menu & windows` 페이지: 우클릭 드롭다운, Settings 창, About 창
  - `Archive` 페이지: 채택하지 않은 시안. 참고용
- 근거가 된 질문과 답: [qa.md](qa.md) (본문의 `Q#`는 그 문서의 질문 번호)
- 동작 규칙(어떤 경기를 보여줄지, 갱신, 오류 처리): [spec.md](spec.md)
- HTML 목업(`mockup.html`)은 Figma 작업 전 기준선이라 삭제했다 (Q70). 같은 내용이 Figma `Archive`의 `00 Baseline`에 있다. 구현은 Figma와 이 문서를 따른다.

## 2. 위젯 카드

한 번에 경기 하나만 표시한다 (Q22). 어떤 경기를 고를지는 [spec.md](spec.md) 5.1절을 따른다.

### 2.1 외곽 (Q60–Q62)

- 모서리는 둥글리지 않는다. 왼쪽 위만 16px 사선으로 잘라 낸다.
  - 경로: `M 16 0 L 320 0 L 320 146 L 0 146 L 0 16 Z` (배율 100%)
  - 배경, 테두리, 틴트, 득점 플래시가 모두 이 모양을 따른다. 사각형으로 칠하면 잘린 모서리에 색이 샌다.
- 테두리: 안쪽 1px, 흰색 9%
- 위쪽 하이라이트: 안쪽 그림자, 흰색 12%, y 1px, 흐림 0
- 카드 그림자: 검정 30%, y 8px, 흐림 24px. 창 크기가 카드와 같으면 잘리므로 창에 그림자 여백이 필요하다.
- 코너 아크: 오른쪽 아래 모서리를 중심으로 한 반지름 88px 원의 4분의 1. 선 1.5px, 흰색 7%, 카드 모양 안으로 잘린다. 축구장 코너 아크에서 따온 디테일이다.

### 2.2 레이아웃

가로 대칭이다 (Q37). 홈팀이 왼쪽, 원정팀이 오른쪽이고 별도의 홈/원정 배지는 없다 (Q13).

실시간:

```
╱─────────────────────────────────┐
│ Premier League                 ↻ │   머리 줄: 대회명, ↻(호버 시)
│   (MCI)       2 – 1      (ARS)   │   경기 줄: 홈 | 가운데 | 원정
│  Man City     ● 67'     Arsenal  │
│  ‾‾‾‾                    ‾‾‾‾    │   키트 줄
│ ──────────────────────────────── │   구분선
│ Goal! 67' Haaland  More details ↗│   바닥 줄: 득점 줄, More details(호버 시)
└──────────────────────────────────┘
```

직전 결과, 다음 경기 (Q63):

```
╱─────────────────────────────────┐
│ Premier League                 ↻ │
│                                  │
│   (MCI)       1 – 3      (ARS)   │   경기 줄이 남은 높이의 가운데로 내려온다
│  Man City   [Full-Time]  Arsenal │
│  ‾‾‾‾                    ‾‾‾‾    │
│          More details ↗          │   호버 시 아래 가운데
└──────────────────────────────────┘
```

- 실시간: 머리 줄, 경기 줄, 바닥 줄(구분선 + 득점 줄)의 세 줄이다.
- 실시간이 아닐 때: 바닥 줄 자리를 없앤다. 경기 줄이 머리 줄 아래 남은 높이를 모두 쓰고 내용은 그 세로 가운데에 온다. `More details ↗`는 카드 아래에서 10px 위, 가로 가운데에 겹쳐 뜬다.
- 경기 줄의 가운데 칸은 폭 104px로 고정하고, 양쪽 팀 칸이 남은 폭을 나눈다.
- 팀 칸에는 로고(40px), 팀명, 키트 줄을 위에서부터 5px 간격으로 놓는다.
- 키트 줄: 16×2px, 그 팀의 ESPN `color` (Q60)
- 대회명과 로고 사이, 팀명과 구분선 사이는 각각 약 10px 띄운다 (Q54).
- 스코어는 홈 점수, `–`, 원정 점수의 세 칸으로 나눈다 (Q55).
  - 양쪽 칸의 폭이 같아서 `–`는 항상 카드 가로 중앙에 있다.
  - 홈 점수는 오른쪽 정렬, 원정 점수는 왼쪽 정렬이고, 둘 다 `–`에서 8px 떨어진다.
  - 점수가 두 자리가 되면 바깥쪽으로 늘어난다. 갱신할 때는 숫자만 바뀐다.
- 스코어 아래 줄은 `–`에 맞춰 가운데 정렬한다. 빨간 점과 경기 시간(`● 67'`)은 5px 간격의 한 묶음으로 정렬하고, 배지는 배지 전체를 정렬한다 (Q56).
- 경기 없음: 팀 칸 없이 카드 가운데에 `No upcoming matches` (Q30).

### 2.3 공통 요소

- 팀 로고: ESPN 팀 `logos` 중 `rel`에 `dark`가 있는 것(어두운 배경용). 없으면 `default`를 쓴다 (예: Coventry City).
- 팀명: ESPN `shortDisplayName` (예: `Man City`, `Spurs`, `Nottm Forest`). 5대 리그에서 가장 긴 것이 13자(`Real Sociedad`)다. 넘치면 말줄임 (Q15, Q49).
- 대회명: ESPN `league.abbreviation` (예: `Premier League`, `UEFA Champions League`) (Q13)

### 2.4 상태별 표시 내용

| 상태 | 가운데 칸 | 바닥 줄 |
|---|---|---|
| 다음 경기 | 킥오프 날짜(위, 작게)와 시각(아래, 크게). 절대 표기, 로컬 타임존 기준 (예: `Oct 24 (Sat)` / `20:00`). 12·24시간제는 설정을 따른다 (Q21) | 없음 |
| 다음 경기 (연기됨) | 위 내용 + 빨간 `Postponed` 배지. 원래 킥오프 시각까지만 표시 (Q20, Q57) | 없음 |
| 실시간 | 스코어, 그 아래 빨간 점 + 경기 상태(ESPN `status.type.shortDetail`, 예: `● 67'`, `● 90'+3'`). 하프타임(`HT`)은 점 없이 노란 `Half-Time` 배지 (Q14, Q53, Q57) | 구분선 + 가장 최근 득점 한 줄 (Q51) |
| 직전 결과 | 최종 스코어, 그 아래 이긴 팀 색의 `Full-Time` 배지. 연장으로 끝난 경기도 같다. 무승부는 중립 배지. 승부차기로 끝났으면 승부차기에서 이긴 팀 색의 `4–3 PEN` 배지 (Q52, Q57, Q58) | 없음 |
| 경기 없음 | `No upcoming matches` (Q30) | 없음 |

득점 줄:
- 형식은 `Goal! 67' Haaland`이고, 가장 최근 득점 한 건만 보여준다. 길면 말줄임.
- ESPN이 정보를 주면 PK는 `(P)`, 자책골은 `(OG)`를 붙인다.
- 경기가 끝나면 없앤다 (Q18).

### 2.5 색

- 톤: 다크 고정 (Q38). 바탕화면 위에 `rgb(24 24 27)`을 반투명하게 깔고(블러 없음, spec 4절), 그 불투명도는 설정의 투명도 값을 따른다. 기본 70% (Q48).
- 글자: 기본은 흰색 95%. 보조 글자(대회명, 경기 상태, 날짜, 득점 줄, More details)는 흰색 62%.
- 스코어와 다음 경기 시각: 그림자 검정 35%, y 1px, 흐림 3px
- 팀 색 틴트 (Q39, Q46, Q59):
  - 이기거나 리드하는 팀 쪽 가장자리(홈=왼쪽, 원정=오른쪽)에서 반대쪽 가장자리까지 선형 그라데이션으로 칠한다.
  - 시작 농도는 팀 색 40%, 반대쪽 끝은 0%.
  - 직전 결과는 이긴 팀 색으로 칠한다. 승부차기는 승부차기에서 이긴 팀이다 (Q13).
  - 실시간은 리드하는 팀 색으로 칠한다 (Q17).
  - 무승부, 실시간 동점, 다음 경기, 경기 없음은 틴트 없이 기본 바탕만 쓴다. 문서의 "중립색"은 이 상태를 말한다.
- 팀 색은 ESPN 팀 `color` 값을 그대로 쓴다. 흰색·검정 팀도 예외 없다. 값이 없으면 틴트 없음 (Q36). 다크 톤이라 검정 팀의 틴트는 거의 보이지 않는다.
- 실시간 점: `#ff3b30`
- 배지 (Q57, Q61): 모서리 반경 2px의 각진 사각형, 안쪽 여백 1px/7px, 글자 10.5px, 굵기 400. 기준색 하나로 글자와 바탕을 만든다.
  - 글자: 기준색 55% + 흰색 45%. 어두운 팀 색도 읽히게 하려는 것이다.
  - 바탕: 기준색 22%.
  - 기준색: `Half-Time`은 노랑 `#ffd60a`, `Postponed`는 빨강 `#ff3b30`, `Full-Time`과 `4–3 PEN`은 이긴 팀의 ESPN `color`.
  - 중립 배지(무승부 `Full-Time`): 글자는 보조 글자색, 바탕은 흰색 10%.

### 2.6 글꼴과 크기

- 글꼴: Outfit (Google Fonts, OFL, latin·latin-ext 포함). 오프라인에서도 보이도록 woff2 파일을 앱에 넣는다 (Q40, Q45).
- 기본 카드 크기: 320×146px (배율 100%, 100% DPI 기준). 가로세로 비율은 고정이고 설정에서 배율을 바꾼다 (Q47). 배율을 바꾸면 아래 수치가 모두 같은 비율로 커지거나 작아진다.

| 요소 | 크기 (배율 100%) | 굵기 |
|---|---|---|
| 스코어 | 30px, 줄 높이 100% | 700 |
| 다음 경기 시각 | 22.5px | 700 |
| 팀명 | 12.5px | 600 |
| 다음 경기 날짜 | 12px | 400 |
| 경기 상태, 득점 줄 | 11.5px | 400 |
| 대회명, More details | 11px | 500 |
| 카드 안쪽 여백 | 위 11px, 아래 12px, 좌우 14px | |
| 머리 줄 높이 / 아래 간격 | 16px / 5px | |
| 바닥 줄 높이 / 위 간격 (실시간만) | 23px(구분선 아래 6px 포함) / 5px | |

### 2.7 모션 (Q64, Q65)

Figma `Motion` 섹션의 프로토타입이 기준이다. Present로 재생하면 흐름별 시작점이 있다.

| 흐름 | 내용 |
|---|---|
| 라이브 점 | 1.4초 동안 빨간 고리가 점 크기(7px)에서 21px까지 퍼지며 사라지고, 그동안 점은 100%에서 35%로 흐려진다. 끝나면 처음으로 돌아가 반복한다. 실시간 상태에서만 돈다 |
| 득점 | 0–350ms: 득점한 팀 쪽 가장자리에서 그 팀 색 플래시(그라데이션 50%, 카드 모양 그대로)가 켜지고, 득점한 팀의 점수 숫자가 위로 굴러 새 숫자로 바뀐다. 350–750ms: 새 득점 줄이 왼쪽 14px에서 밀려 들어온다. 750–1650ms: 플래시가 천천히 빠진다 |
| 뒤지는 팀 득점 | 위와 같다. 플래시는 득점한 팀 쪽에서 나오고, 리드 팀이 그대로면 틴트는 바뀌지 않는다 |
| 호버 | ↻와 `More details ↗`가 150ms 동안 서서히 나타난다 |
| 경기 종료 | 450ms 동안 경기 시간·구분선·득점 줄이 사라지고, 경기 줄이 가운데로 내려오며, `Full-Time` 배지가 이긴 팀 색으로 떠오른다 |

- 플래시와 점수 굴림은 점수가 바뀐 것을 갱신에서 처음 확인했을 때 한 번만 재생한다. 앱을 다시 켜서 캐시로 그린 경우에는 재생하지 않는다.

## 3. 버튼과 조작

| 대상 | 조작 | 결과 |
|---|---|---|
| 카드 아무 곳 | 클릭 | 기본 브라우저로 구글 검색 (검색어 형식은 [spec.md](spec.md) 5.2절) (Q23). 경기 없음 상태에서는 아무 일도 없음 |
| 카드 아무 곳 | 드래그 | 위젯 이동. 위치 잠금이 켜져 있으면 움직이지 않음 (Q6, Q27) |
| 카드 | 마우스 오버 | 오른쪽 위에 ↻, `More details ↗` 표시 (실시간은 오른쪽 아래, 그 외는 아래 가운데) (Q24, Q50, Q63). 경기 없음 상태에서는 ↻만 |
| 새로고침 버튼 ↻ | 클릭 | 즉시 갱신. 5초 쿨다운 (Q24) |
| 카드 | 우클릭 | 드롭다운 메뉴 (Q66) |
| 트레이 아이콘 | 우클릭 | 같은 드롭다운 메뉴 (Q68) |
| `Update` 배지 | 클릭 | About의 `Download ↗`와 같이 GitHub Releases(latest) 페이지 열기. 설치본 자동 설치는 아직 없음 (Q4) |

- `More details ↗`는 별도 버튼이 아니다. "카드를 누르면 자세한 정보를 볼 수 있다"는 안내이고, 카드 어디를 눌러도 결과는 같다.
- 클릭과 드래그는 누른 뒤 움직인 거리로 구분한다.
- 아이콘(↻, ↗, ⚠, 메뉴 아이콘)은 선 굵기 1.4–1.6px의 인라인 SVG다.

### 3.1 드롭다운 메뉴 (Q66–Q68)

```
╱──────────────────────┐
│ ⚙  Settings          │   → Settings 창
│ ↻  Refresh now       │   → 즉시 갱신 (창 없음)
│ ⓘ  About             │   → About 창
│ ──────────────────── │
│ ⏻  Quit              │   → 앱 종료
└──────────────────────┘
```

- 우클릭한 위치(트레이는 트레이 아이콘 근처)에 뜬다. 메뉴 밖을 누르거나 항목을 고르면 닫힌다.
- Windows 기본 트레이 메뉴는 모양을 바꿀 수 없다. 그래서 트레이 우클릭도 위젯과 같은 프레임리스 팝업 창으로 띄운다.
- `Refresh now`는 ↻와 같은 쿨다운·요청 제한을 따른다. 그동안 흐리게(글자 흰색 38%) 표시하고 오른쪽에 남은 초(`4s`)를 보여준다.
- 모양:
  - 폭 196px, 안쪽 여백 5px, 왼쪽 위 8px 사선 컷
  - 바탕 `rgb(24 24 27)` 86%, 테두리·하이라이트·그림자는 카드와 같다
  - 항목: 높이 32px, 안쪽 여백 9px/10px, 아이콘 14px, 아이콘과 글자 사이 10px
  - 글자: 12.5px, 굵기 400, 흰색 92%. 아이콘과 세로 가운데가 맞도록 글자 상자를 대문자 높이로 잘라 정렬한다(Figma `leadingTrim: CAP_HEIGHT`, CSS `text-box: trim-both cap alphabetic`) (Q67).
  - 호버: 흰색 8% 바탕, 왼쪽 위 5px 사선 컷 (Q67)
  - 구분선: 흰색 10%, 위아래 3px, 좌우 6px 여백

## 4. 상태 표시

| 표시 | 언제 | 내용 |
|---|---|---|
| ⚠ 아이콘 | 갱신이 연속 2회 실패 (Q31) | 마우스를 올리면 마지막 갱신 시각 |
| ⚠ 툴팁 (요청 제한) | `429`·`403`으로 대기 중 | 다음 시도 시각. 이 동안 ↻와 `Refresh now` 비활성 |
| ⚠ 툴팁 (영구 오류) | 요청 자체가 잘못됨 | `Data unavailable — update may be required` |
| `Update` 배지 | 새 버전이 있음 (Q4) | 머리 줄 ↻ 왼쪽에 `Half-Time`과 같은 노란(`#ffd60a`) 각진 배지. ↻와 달리 호버 없이 항상 보인다. 앱 시작 때와 1시간마다 About과 같은 GitHub API로 확인하고, 확인에 실패하면 직전 결과를 유지한다. Figma `E Update 배지`. 클릭 동작은 3절 |

오류 분류와 재시도 규칙은 [spec.md](spec.md) 8절에 있다.

## 5. 창 공통 (Q42)

첫 실행, Settings, About 창은 위젯과 같은 프레임리스 다크 반투명 창이다.

- 외곽: 왼쪽 위 16px 사선 컷, 바탕 `rgb(24 24 27)` 86%, 테두리·하이라이트·그림자는 카드와 같다. 오른쪽 아래에 코너 아크(Settings 반지름 140px, About 90px, 흰색 6%).
- 제목 줄: 제목 15px 굵기 600, 오른쪽에 ✕(28px 영역). 제목 줄을 끌어서 옮긴다(`data-tauri-drag-region`).
- 안쪽 여백: 위 14px, 아래 22px, 좌우 24px
- 섹션 이름: 11px 굵기 500, 흰색 55%
- 바탕화면에 고정하지 않는다. 일반 창처럼 다른 창 위에 뜬다.

## 6. Settings 창 (Q69)

폭 560px. 바꾼 값은 즉시 반영되므로 저장 버튼이 없다. 맨 아래에 `Changes apply immediately.`(11px, 흰색 45%).

| 영역 | 내용 |
|---|---|
| `Your team` | 리그 탭(EPL, LALIGA, Bundesliga, Serie A, Ligue 1). 고른 탭은 굵기 600 + 아래 2px 흰색 밑줄, 나머지는 흰색 55% (Q9) |
| 팀 격자 | 5열, 칸 사이 8px. 칸마다 로고 40px + `shortDisplayName`(11.5px). 리그당 18~20팀이 스크롤 없이 들어간다 (Q43). 선택된 팀: 흰색 8% 바탕 + 1px 흰색 16% 테두리 + 팀 색 키트 줄 |
| 구분선 | 흰색 10% |
| `Widget` | 아래 설정 줄들. 줄 높이 34px, 이름(13px, 흰색 92%)은 왼쪽, 컨트롤은 오른쪽 |

| 설정 | 컨트롤 |
|---|---|
| `Start with Windows` | 토글 |
| `Size` | 슬라이더 + 값(`320 × 146`). 비율 고정, 카드 너비 260–420px (배율 약 80–130%) (Q47) |
| `Opacity` | 슬라이더 + 값(`70%`). 기본 70% (Q48) |
| `Lock position` | 토글 |
| `Time format` | `12-hour` / `24-hour` 두 칸 선택 |

- 토글: 34×18px, 모서리 2px. 켜짐은 흰색 90% 바탕 + 어두운 손잡이(오른쪽), 꺼짐은 흰색 14% 바탕 + 흰색 75% 손잡이(왼쪽). 손잡이 14×14px, 모서리 1px.
- 슬라이더: 트랙 180×2px(흰색 14%), 채워진 부분 흰색 90%, 손잡이 8×14px 흰색, 모서리 1px. 값은 오른쪽 68px 칸에 오른쪽 정렬(12px, 흰색 62%).
- 두 칸 선택: 1px 흰색 14% 테두리, 칸 여백 4px/12px, 고른 칸은 흰색 12% 바탕 + 흰색 95% 글자.

## 7. 첫 실행 화면

Settings 창과 같은 창에서 팀 영역만 보여준다 (Q8, Q12, Q44). Figma에는 아직 그리지 않았다.

1. 제목 `Pick your team`
2. 리그 탭 + 팀 격자 (Settings 창과 같음)
3. `Start with Windows` 체크박스
4. `Start` 버튼 → 위젯 표시. 팀을 고르기 전에는 비활성.

팀을 고르지 않고 ✕로 닫으면 앱을 종료한다.
