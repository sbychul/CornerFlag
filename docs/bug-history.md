# CornerFlag 버그·수정 이력

2026-10-29 기준. 코드를 바꾸기 전에 [지켜야 할 불변 조건](#지켜야-할-불변-조건)을 먼저 확인한다.

## 개요

2026-10-19 v1.0.0 이후 10월 29일까지 버그 31건을 고쳤다. 11건은 v1.0.0~v1.1.3에, 13건(커밋 d518fba, bac9725, fba5600, 09714a9)은 v1.2.0에 배포됐고, 7건은 아직 배포 전이다. fba5600의 6건은 여러 팀 표시를, 미배포 7건은 저장소 전체를 리뷰하다 찾았다.

- 근거: `git log`의 `fix:` 커밋 본문, GitHub 이슈 sbychul/cornerFlag#1·#2, [.scratch/cornerflag-v1/verification.md](../.scratch/cornerflag-v1/verification.md)
- 범위: 동작·표시 버그만 다룬다. README 문구 수정(17ffd8e)은 제외했다.
- 가장 많은 원인은 macOS·혼합 DPI 환경의 좌표 단위 혼용(4건)이다.

## 남은 이슈·관찰 사항

열린 GitHub 이슈는 없다(#1, #2 모두 종료). 다만 아래 항목은 확인이 필요하다.

- 미대응 현상: 프로그램이 `SetForegroundWindow`로 위젯을 활성화하면 다른 창 위로 올라와 Win+D 왕복 후에도 남는다. 사용자 클릭으로는 생기지 않아 보류했고, 위젯을 활성화하는 기능이 생기면 `WS_EX_NOACTIVATE`를 적용한다(verification.md 6.5).
- 외부 의존 위험: Windows 아크릴릭은 비공개 API SWCA(`ACCENT_ENABLE_ACRYLICBLURBEHIND`)를 쓴다. Windows 업데이트로 깨질 수 있고, 그때는 CSS 반투명 배경으로 대체한다.
- 재발 위험: ESPN 응답은 폴링 간 일시적으로 어긋나거나 일부가 깨질 수 있다. 새 표시 항목은 스코어·상태와 맞춰 보여주고 `src/espn.test.mjs`에 케이스를 남긴다.
